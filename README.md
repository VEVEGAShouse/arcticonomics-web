# arctic-onomics.com

Arcticonomics, una teoría de FRONTTIER por Virginia E. Vegas: la economía del Ártico es contracíclica a la del mundo.

- `/` (v1): noche polar; la cordillera es el precio real del petróleo.
- `/v2/`: el Círculo Polar Ártico como horizonte; el precio arriba y su reflejo rojo abajo.
- `data.js`: precio mensual del WTI (FRED, WTISPLC), enero 1947 – octubre 2026, nominal y real (deflactado con el IPC de EE. UU., CPIAUCSL, a dólares de octubre de 2026). Octubre de 2025 interpolado (no se publicó el IPC).
- Los eventos están en la lista `EV` de cada `app.js`.

Publicado gratis con GitHub Pages.
